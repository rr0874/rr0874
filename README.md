## 🚀 Featured Project

### GradeSense
**NLP-Driven Conversational Analytics Platform for Academic Performance Intelligence**

A local NLP-based platform that allows users to analyze academic performance data using natural-language queries. It works with Excel-based student result data and provides insights such as student profiles, toppers, backlogs, pass rates, SGPA trends and academic summaries.

**Tech:** Python • NLP • spaCy • Scikit-learn • SQLite • Pandas • OpenPyXL • Streamlit
